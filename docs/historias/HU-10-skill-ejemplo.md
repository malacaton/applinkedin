# HU-10: Skill de ejemplo

**Como** usuario del servidor MCP
**quiero** una skill que le indique a mi asistente cómo usar las herramientas y qué criterios editoriales seguir
**para** obtener propuestas coherentes sin repetir instrucciones en cada conversación.

## Criterios de aceptación

- El repositorio incluye una skill de ejemplo genérica (`SKILL.md`), sin datos personales.
- Explica cuándo usar cada herramienta del MCP.
- Incluye criterios editoriales de ejemplo (longitudes, convenciones) claramente marcados como personalizables.
- El manual de HU-09 explica cómo instalar la skill y cómo adaptarla.
