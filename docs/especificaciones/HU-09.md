# Especificación HU-09: Instalación y uso con Claude Desktop

- **Historia:** [HU-09](../historias/HU-09-instalacion.md)
- **Estado:** Aprobada
- **Fecha:** 2026-11-15
- **Depende de:** [HU-08](HU-08.md) (servidor MCP) y la CLI (HU-03 a HU-07)

## 1. Objetivo

Que alguien que descubre el proyecto en GitHub pueda instalarlo, conectarlo a Claude Desktop y probarlo en unos minutos, sin leer el código. Es una historia de documentación con un ejemplo que se comprueba automáticamente.

## 2. Entregables

| Entregable | Contenido |
| --- | --- |
| `docs/manual.md` | Manual de instalación y uso (§3) |
| `ejemplo/` en la raíz | Carpeta de contenido mínima, lista para probar (§4) |
| `README.md` | Enlace al manual en "Instalación". La sección actual de instalación se resume y remite al manual |
| Test de ejemplo | Comprueba que el ejemplo carga sin errores y da los resultados que cita el manual (§5) |

## 3. Manual (`docs/manual.md`)

Secciones, en este orden:

1. **Requisitos:**
   - SDK de .NET 10, o solo el runtime si se usa una versión publicada.
   - Git.
   - Claude Desktop u otro cliente compatible con MCP.
   - Sistemas: Windows y macOS (los dos que tienen Claude Desktop). En Linux funciona la CLI y cualquier cliente MCP por stdio.
2. **Compilar:**
   - `git clone`.
   - `dotnet publish back/src/Ali.Mcp -c Release -o <carpeta>` y lo mismo para `Ali.Cli`.
   - Las rutas resultantes (`ali-mcp.dll`, `ali.dll`).
   - Con `dotnet publish` las rutas son estables y no dependen de `bin/`.
3. **Tu carpeta de contenido:**
   - Los metadatos del bloque YAML (tabla de campos de HU-01) y la regla de nombres de las piezas.
   - Copiar `ejemplo/` como punto de partida.
4. **El fichero de series:**
   - Los campos de HU-02 y de HU-07, con el ejemplo comentado.
   - Dónde se busca: `--series`, `ALI_SERIES` o `series.yaml`.
5. **Conectar con Claude Desktop:**
   - Ruta de `claude_desktop_config.json`:
     - Windows: `%APPDATA%\Claude\`.
     - macOS: `~/Library/Application Support/Claude/`.
   - La entrada exacta, con `dotnet` + `ali-mcp.dll` + `--contenido`, y opcionalmente `--series`.
   - Notas sobre las barras invertidas en JSON en Windows.
6. **Comprobar que funciona:**
   - Reiniciar Claude Desktop.
   - Ver las cinco herramientas en el menú de herramientas.
   - Probar con preguntas de ejemplo: "¿Qué piezas tengo programadas?", "Propón las próximas fechas libres de casos-reales" y "Valida mi calendario del próximo mes".
   - Qué esperar con la carpeta `ejemplo/`.
7. **Otros clientes:**
   - Claude Code: `claude mcp add applinkedin -- dotnet <ruta>/ali-mcp.dll --contenido <carpeta>`.
   - Cualquier cliente MCP por stdio: mismo comando y argumentos.
8. **Usar la CLI:** resumen de los cinco comandos con un ejemplo de cada uno sobre `ejemplo/`, y la variable `ALI_CONTENIDO`.
9. **Problemas frecuentes:**

   | Problema | Causa y solución |
   | --- | --- |
   | Las herramientas no aparecen | JSON de configuración inválido o ruta del `.dll` incorrecta. Mirar los registros de MCP de Claude Desktop |
   | "No existe la carpeta de contenido" | Ruta mal escrita o con barras sin duplicar en JSON |
   | "No existe el fichero de series" | Falta `series.yaml` en la carpeta, o la ruta de `--series` está mal |
   | `dotnet` no se encuentra | El SDK o el runtime no está instalado o no está en el `PATH`. Se puede indicar la ruta completa a `dotnet` |
   | Cambios que no se ven | No hace falta reiniciar: se leen en cada llamada. Si se cambió la configuración del cliente, sí hay que reiniciarlo |

10. **Privacidad:**
    - Todo es local. El servidor no se conecta a Internet ni a LinkedIn (ADR-0003 y ADR-0005).
    - El cliente de IA sí envía al modelo lo que lee con las herramientas, según sus propias condiciones.

## 4. Carpeta `ejemplo/`

```
ejemplo/
├── series.yaml                 casos-reales (martes, semanal), fundamentos (lunes y jueves, quincenal),
│                               resumen-caso (despues_de casos-reales, 2 días), notas (libre)
├── casos/
│   ├── 01-agentes-en-produccion.md     publicado
│   ├── 02-memoria-de-los-agentes.md    programado
│   └── 03-evaluar-un-rag.md            borrador, sin fecha
├── fundamentos/
│   └── 01-que-es-un-token.md           listo
├── resumenes/
│   ├── 01-agentes-en-produccion.md     idea, depende de casos/01
│   └── 03-evaluar-un-rag.md            idea, depende de casos/03 (en borrador: bloqueada)
└── notas/
    └── ideas-sueltas.md                idea, sin serie (sin clasificar)
```

- **Contenido:** textos breves y genéricos, sin datos personales ni de empresas (CLAUDE.md).
- **Fechas:** son **fijas** (noviembre y diciembre de 2026) para que el test sea determinista. El manual explica que, para verlas como futuras, se usa `--desde 2026-11-15`, o se cambian las fechas.
- **Problemas a propósito:** el ejemplo incluye una pieza bloqueada y un hueco, para que `validar` muestre algo útil.

## 5. Test del ejemplo

Un test en `Ali.Cli.Tests` ejecuta la CLI sobre `ejemplo/` con la fecha fija 2026-11-15 y comprueba:

- `listar` da las 7 piezas, sin avisos.
- El fichero de series carga sin errores.
- `huecos casos-reales` da las fechas que cita el manual.
- `validar` da exactamente los problemas que cita el manual.

Si alguien cambia el ejemplo sin actualizar el manual, el test lo detecta.

## 7. Fuera de alcance

- Publicar paquetes (NuGet, `dotnet tool`, instaladores o binarios en GitHub Releases).
- Ejecutables autocontenidos (sin .NET instalado).
- Configuración para otros clientes con más detalle que el comando genérico.
- Manual en inglés.

| Pregunta | Decisión |
| --- | --- |
| Forma de instalar | `dotnet publish` a una carpeta fija; `dotnet tool` queda para más adelante |
| Ubicación del ejemplo | `ejemplo/` en la raíz |
| Fechas del ejemplo | Fijas (noviembre y diciembre de 2026); el manual usa `--desde 2026-11-15` |
| Prueba manual en Claude Desktop | La hace el usuario; queda como pendiente en la PR |

## 9. Ajuste durante la implementación

- El test comprueba algo más que los resultados del ejemplo: lee `docs/manual.md` y verifica que cada salida citada aparece tal cual. Así el manual no puede quedar desactualizado.
