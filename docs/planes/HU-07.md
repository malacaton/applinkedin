# Plan y tareas HU-07: Crear una pieza nueva

- **Especificación:** [HU-07](../especificaciones/HU-07.md)
- **Fecha:** 2026-11-15

## Diseño técnico

### Núcleo

| Tipo | Responsabilidad |
| --- | --- |
| `Series` (+ `Folder`, `FileName`) | Campos nuevos opcionales; `ResolvedFolder` y `ResolvedFileName` aplican los valores por defecto |
| `FileNameTemplate` | Interpreta y valida la plantilla (`{n}`, `{nn}`, `{nnn}`, `{titulo}`, `{fecha}`) y la resuelve |
| `TitleSlug` | Convierte el título en texto de fichero (§4) |
| `SeriesConfigLoader` | Lee y valida `carpeta` y `fichero` |
| `NewPiece` / `CreatedPiece` / `PieceCreationException` | Petición, resultado y error |
| `PieceCreator.Create` | Valida, numera, busca la fecha (con la reserva blanda), construye el contenido, lo comprueba con el lector de HU-01 y lo crea con `FileMode.CreateNew` |

- **Reserva blanda:** se recorren los huecos de `SlotFinder.Enumerate` sin límite y se descartan las fechas que ya tenga cualquier pieza de la serie.
- **Formato del YAML:**
  - Los valores se escriben sin comillas cuando es seguro.
  - `formato` y `depende_de` van entre comillas dobles si contienen caracteres especiales de YAML. La comprobación con el lector garantiza que se leen igual.

### CLI

| Tipo | Responsabilidad |
| --- | --- |
| `CreateCommand` | `ali crear <serie> <titulo>` con `-c`, `--series`, `--fecha`, `--fecha-libre`, `--desde`, `--formato` y `--depende-de` |
