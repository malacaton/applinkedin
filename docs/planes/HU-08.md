# Plan y tareas HU-08: Servidor MCP

- **Especificación:** [HU-08](../especificaciones/HU-08.md)
- **Fecha:** 2026-11-15

## Diseño técnico

### Núcleo: código compartido

| Tipo | Responsabilidad |
| --- | --- |
| `Ali.Core.Output.JsonOutput` | Opciones del serializador (sangría, tildes sin escapar) y `Serialize` |
| `Ali.Core.Output` (documentos) | `ListDocument`, `SlotsDocument`, `ReportDocument`, `UpdateDocument` y `CreatedDocument`, cada uno con `From(...)` |
| `Ali.Core.Input.DateInput` | Fecha `AAAA-MM-DD` u `hoy` y su mensaje de error, con el nombre del parámetro |
| `Ali.Core.Input.ContentLocation` | Variables `ALI_CONTENIDO` y `ALI_SERIES` y resolución del fichero de series |
| `PieceStatusNames.InvalidMessage` | Mensaje de estado no válido, común a CLI y MCP |

La CLI pasa a usar estos tipos, y sus escritores JSON propios desaparecen. Los tests de la CLI no cambian.

### Servidor (`Ali.Mcp`)

| Tipo | Responsabilidad |
| --- | --- |
| `Program` | Lee los argumentos, comprueba la carpeta y monta el host con `AddMcpServer().WithStdioServerTransport().WithTools<AliTools>()`. El registro va a stderr |
| `ServerSettings` | Carpeta de contenido, fichero de series (o `null` para el de por defecto) y entorno |
| `StartupArguments` | Lee `--contenido` y `--series`; aplica las reglas de §2 |
| `AliTools` | Las cinco herramientas, que reciben `ServerSettings` y `TimeProvider`. Los errores de dato se lanzan como `McpException` |

- **AssemblyName:** `ali-mcp`.
- **Paquetes:** `ModelContextProtocol` 2.4.0 y `Microsoft.Extensions.Hosting` 10.0.15.

### Pruebas (`Ali.Mcp.Tests`)

- **`AliToolsTests`:**
  - Cada herramienta con una carpeta temporal y un reloj fijo.
  - Comparación con el JSON de la CLI.
  - Errores y relectura entre llamadas.
- **`McpServerProcessTests`:**
  - Arranca `ali-mcp.dll` con `dotnet` y se conecta con el cliente stdio del SDK.
  - Comprueba la lista de herramientas, las anotaciones, una llamada correcta y un error con `isError`.
  - Comprueba el arranque fallido sin carpeta.
