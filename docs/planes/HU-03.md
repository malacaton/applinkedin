# Plan y tareas HU-03: Listar piezas con filtros

- **Especificación:** [HU-03](../especificaciones/HU-03.md)
- **Fecha:** 2026-11-14

## Diseño técnico

### Núcleo (`Ali.Core.Content`)

| Tipo | Responsabilidad |
| --- | --- |
| `Piece.EffectiveDate` | `PublishedDate ?? PlannedDate` |
| `PieceQuery` | Filtros: series, sin clasificar, estados y rango. `Validate()` devuelve el error de rango, o `null` |
| `PieceFilter.Apply` | Filtra y ordena (fecha, sin fecha al final, desempate por ruta ordinal) |

### CLI (`Ali.Cli`)

| Tipo | Responsabilidad |
| --- | --- |
| `CliApp.Run(args, out, err, entorno, carpetaActual)` | Monta el `RootCommand` y lo invoca con `TextWriter` inyectados; devuelve el código de salida |
| `ListCommand` | Opciones de `listar`, validación de estados y fechas, resolución de la carpeta, ejecución |
| `TextListWriter` / `JsonListWriter` | Formato de texto (tabla alineada y total) y JSON (`piezas` y `avisos`) |
| `Program` | Pone la consola en UTF-8 y llama a `CliApp.Run` con la consola real |

- **Nombre del ejecutable:** `AssemblyName` = `ali`.
- **JSON:** `System.Text.Json` con sangría y `UnsafeRelaxedJsonEscaping`, para que las tildes salgan tal cual. Es seguro porque la salida no se incrusta en HTML.
- **Dependencia:** `System.CommandLine` 3.0.0 (ADR-0008).

### Pruebas

- `Ali.Core.Tests`: `PieceFilterTests` (filtros, rango y orden).
- Proyecto nuevo `Ali.Cli.Tests`: ejecuta `CliApp.Run` con `StringWriter` y carpetas temporales. Reutiliza `TempContentFolder` enlazando el fichero, sin copiarlo.
