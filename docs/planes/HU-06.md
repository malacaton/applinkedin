# Plan y tareas HU-06: Validar el calendario

- **Especificación:** [HU-06](../especificaciones/HU-06.md)
- **Fecha:** 2026-11-15

## Diseño técnico

### Núcleo (`Ali.Core.Scheduling`)

| Tipo | Responsabilidad |
| --- | --- |
| `ProblemKind` y `ProblemKindNames` | Los ocho tipos, en el orden de la tabla de §3, y su nombre (`choque`, `hueco`…) |
| `CalendarProblem` / `CalendarReport` | Problema (tipo, fecha, serie, piezas y detalle) e informe del rango |
| `CalendarValidationException` | Rango inválido o serie del filtro inexistente |
| `CalendarValidator.Validate` | Ejecuta las comprobaciones, aplica el filtro y ordena |
| `SlotFinder.Enumerate` (interno) | Huecos sin límite de cantidad, acotados por la fecha final. `Find` pasa a usarlo |
| `PieceReference` (interno) | Normaliza una referencia `depende_de` (sin `.md`, con `/`); lo comparten HU-05 y HU-06 |

**Comprobaciones:**

- **Por grupos:** los choques se agrupan por serie y fecha.
- **Huecos:** se obtienen de `SlotFinder.Enumerate` para cada serie con regla.
- **Dependencias:** se resuelven con un índice de rutas normalizadas, sin distinguir mayúsculas. Por cada dependencia se evalúa, en este orden:
  1. Rota.
  2. `orden`; si no lo es, `desfase`.
  3. `bloqueada`, que es independiente de las anteriores.

### CLI (`Ali.Cli`)

| Tipo | Responsabilidad |
| --- | --- |

| `TextValidationWriter` / `JsonValidationWriter` | Tabla de §2 y JSON de §4 |
| `SeriesFile.Resolve` | Resolución del fichero de series, compartida con `huecos` |
