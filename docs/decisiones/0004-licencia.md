# ADR-0004: Licencia Apache-2.0

- **Estado:** Aceptada
- **Fecha:** 2026-11-12

## Decisión

El proyecto se publica bajo Apache License 2.0.

## Motivos

- Permisiva y conocida en entornos empresariales.
- Incluye concesión explícita de patentes, que MIT no tiene.
- El uso de una IA de pago lo decide y lo paga cada usuario con su propio cliente o clave; no requiere ninguna cláusula en la licencia.

## Alternativas descartadas

- **MIT:** más corta, sin cláusula de patentes.
- **AGPL-3.0:** dificulta el uso en empresas.
